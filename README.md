# UTEHY Lite

Một tiện ích mở rộng cho trang web sinh viên UTEHY

## Tính năng chính

<li>Lưu thông tin đăng nhập: Giúp bạn đăng nhập tự động mỗi lần mở trang web</li>
<li>Xem điểm nhanh: Cho phép xem điểm số không cần đánh giá</li>
<li>Tải lịch học: Tải xuống lịch học để có thể dễ dàng thêm vào ứng dụng lịch của bạn</li>
<br>

## Cách xây dựng tiện ích mở rộng

**Hoặc có thể tải bản dựng sẵn tại phần Releases**

<ol>
  <li>Tải source code: Sử dụng <pre><code>git clone https://github.com/tuanvuchu0/UTEHYLite.git</code></pre> để lấy mã nguồn, hoặc tải file ZIP và giải nén vào máy tính.</li>
  <li>Cài đặt các module: Vào thư mục project và chạy lệnh:</li>
  <pre><code>npm install</code></pre>
  <p>để cài đặt tất cả các dependency cần thiết.</p>
  <li>Build project: Chạy lệnh:</li>
  <pre><code>npm run build</code></pre>
  <p>Thư mục <strong>dist</strong> sẽ xuất hiện sau khi build thành công.</p>
  <li>Cài trong trình duyệt:</li>
  <ul>
    <li>Mở Chrome/Edge → <strong>Extensions</strong> → bật <strong>Developer Mode</strong> → chọn <strong>“Load unpacked”</strong>.</li>
    <li>Chọn thư mục <code>dist</code> để cài tiện ích.</li>
  </ul>
</ol>
